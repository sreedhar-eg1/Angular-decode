Component Input binding in Angular Router
    Modern angular allows us to bind some params in the route state to input property

    ...
    {
        path: "demo/:entityId",
        component: SomeComponent,
        data: {
            title: "Some title",
            description: "Some description"
        }
    }
    ...

    ...
    export class SomeComponent {
        @Input() entityId: string = ""
        @Input() title: string = ""
        @Input() description: string = ""
    }
    ...

So from route, we pass some data using data property, we can access it from our component using @Input() decorator


But this feature is not enabled by default
    We need to enable it to use this feature
    withComponentInputBinding() passed to provideRouter, we can enable it

    so in app config file, 
        ...
        providers: [
            provideRouter(routes, withComponentInputBinding())
        ]
        ...

The above approach is to enable it for standalone architecture
To enable it for NgModule approach check the below config

@NgModule({
    imports: [
        RouterModule.forRoot(routes, {
            bindToComponentInputs: true
        })
    ]
})


If we have same name field across params, queryParams and data
    Angular resolves it by assigning a priority to each
        data => highest priority
        params => intermediate priority
        queryParams => least priority
